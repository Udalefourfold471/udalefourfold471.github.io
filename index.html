🧐 What Is Verbatime?

Verbatime is a tool for people who work with Java programs. It watches every single method that your program calls and creates a clear visual chart showing exactly what happened. This chart is called a flame chart.

Most other tools sample your program — meaning they take random guesses. Verbatime doesn't guess. It records everything. No missing pieces. No approximations. You see exactly what your code did, from start to finish.

The results show up inside a free program called JDK Mission Control, which is a powerful viewer. Think of Verbatime as the camera and JDK Mission Control as the screen.

💡 Why Use Verbatime?

  • No sampling, no guessing — every call is recorded. You get the full picture, not just a peek.
  • Easy to understand — the flame chart shows you exactly which methods took time and how they were called.
  • Works with JDK Mission Control — this is a trusted, free tool from the Java community.
  • You choose what to trace — you don't have to record everything. Pick only the methods you care about.
  • Great for fixing slow programs — if your program is slow, Verbatime shows you exactly why.

⚙️ How It Works

Verbatime uses a special technique called bytecode instrumentation. This sounds technical, but here's a simple way to think about it:

Your Java program is made of instructions. Verbatime adds tiny markers to those instructions before your program runs. These markers silently note down when each method starts and stops. Nothing is left out.

Because it works at this deep level, Verbatime is very accurate. It doesn't rely on timing tricks or random checks. It sees the truth.

The data is then formatted so JDK Mission Control can display it as a beautiful, interactive flame chart. You can hover, zoom, and explore every corner of your program's behavior.
